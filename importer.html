Novità V2.7 · Browser Import

Estrai e importa la giornata

SoccerSTATS blocca le richieste automatiche provenienti da Render. La V2.7 legge invece la pagina che hai già aperto nel tuo browser: usa MagicScanner Extract, poi incolla qui il contenuto oppure carica il file HTML creato dal comando.
1. Installa una volta l'estrattore nel browser
Trascina il pulsante qui sotto nella barra dei preferiti. Poi, quando sei su una pagina SoccerSTATS, cliccalo: prova a copiare l'HTML negli appunti; se il browser non lo consente, scarica automaticamente un file .html.
